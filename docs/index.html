Physics Model GUI and Checkpoints Validation and Caveats

Quick Start

python run_gui.py

The first screen is the simulator. Set detector count, per-pixel activity, energy resolution, resolving time, target exposure, and chunk size. Press Start to accumulate binned Poisson counts. Progress is saved after each completed chunk in runs/.

Implemented Deliverables

  • Ho-163 calorimetric spectrum with a simplified Lorentzian shell model.
  • Gaussian detector response using the requested FWHM.
  • Unresolved pileup as a self-convolution with f_pp = A tau_eff.
  • Live histogram of accumulated counts in the endpoint-region fit window.
  • Fisher-matrix estimate of the 90% neutrino-mass sensitivity.
  • Checkpoint and resume using JSON metadata and compressed NumPy arrays.
  • Optional GPU switch with honest CPU fallback when CUDA Python support is absent.

Corrected Planning Point

The Holmes notes sometimes describe 0.2 eV FWHM as a 10x improvement over a 1 eV HOLMES benchmark. That is a 5x improvement. The simulator uses the direct input values and therefore applies the corrected scaling.
