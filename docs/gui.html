Controls

  • New builds a fresh run from the current fields.
  • Update spectra redraws spectra from edited fields. During an accumulated run it is a preview and does not change saved run parameters.
  • True m_nu sets the injected neutrino mass in meV. The default is 100 meV.
  • Parallel fit runs sets the number of independent pseudo-experiment fits used for the signed-fit mean and standard-deviation band. The default is 5.
  • Start accumulates chunks until paused or target years are reached.
  • Pause stops after the current chunk.
  • Save writes the current checkpoint.
  • Load resumes from a saved JSON checkpoint.

Checkpoint Files

Each run writes two files under runs/. The JSON file stores inputs, exposure, sensitivity history, and RNG state. The NPZ file stores accumulated counts and bin edges.

GPU Switch

The checkbox requests GPU acceleration. The current machine has an NVIDIA RTX A4000 visible to the driver, but the installed PyTorch package is CPU-only. Therefore the simulator reports a CPU fallback. To activate CUDA, install a CUDA-enabled PyTorch build matching the local driver, then restart the GUI.

Displayed Estimates

The live Fit m_nu^2 remains the fit to the accumulated histogram. At each saved exposure, the sensitivity plot additionally draws independent pseudo-experiment histograms and fits them concurrently. It displays the mean signed square-root fit and shades one standard deviation. Separately, it computes the RMS error of the physical fitted mass relative to the injected mass. It fits only the newer half of those RMS-error points to A / sqrt(t), then projects when that curve reaches half of the true neutrino mass. This is the estimated exposure for a measurement with approximately +/-50% physical mass accuracy.

Plots

The upper plot shows the full model spectrum from 0 to 2Q + 50 eV, which is the grid used for the pileup self-convolution. It overlays the single-event Ho spectrum, the measured mixed spectrum, the normalized pileup energy-shape curve, and the pileup events that pass the timing filter, scaled by f_pp. The shaded band marks the endpoint window used for the accumulated-count histogram and fit.

The middle plot shows accumulated Poisson counts only inside the selected endpoint fit/display window. It overlays cumulative expected total, single-Ho, and accepted-pileup counts for the active accumulated exposure (or the first chunk before accumulation starts). The simulator does not currently save a full-spectrum count histogram; the full-spectrum panel is the current model density used to construct the endpoint probabilities.
