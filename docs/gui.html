Controls

  • New builds a fresh run from the current fields.
  • True m_nu sets the injected neutrino mass in meV. The default is 75 meV.
  • Start accumulates chunks until paused or target years are reached.
  • Pause stops after the current chunk.
  • Save writes the current checkpoint.
  • Load resumes from a saved JSON checkpoint.

Checkpoint Files

Each run writes two files under runs/. The JSON file stores inputs, exposure, sensitivity history, and RNG state. The NPZ file stores accumulated counts and bin edges.

GPU Switch

The checkbox requests GPU acceleration. The current machine has an NVIDIA RTX A4000 visible to the driver, but the installed PyTorch package is CPU-only. Therefore the simulator reports a CPU fallback. To activate CUDA, install a CUDA-enabled PyTorch build matching the local driver, then restart the GUI.

Displayed Estimates

The live Fit m_nu^2 is a signed linearized Poisson fit to the accumulated histogram with nuisance directions for normalization, flat background, and pileup scale. Because statistical fluctuations can drive m_nu^2 negative, the GUI also shows Physical m_nu, which is clipped to zero before taking the square root. The plot displays a signed square-root scale for the fitted m_nu^2 so negative excursions remain visible instead of flattening at zero.

Plots

The upper plot shows the full model spectrum from 0 to 2Q + 50 eV, which is the grid used for the pileup self-convolution. It overlays the single-event Ho spectrum, the measured mixed spectrum, and the unresolved-pileup contribution scaled by f_pp. The shaded band marks the endpoint window used for the accumulated-count histogram and fit.

The middle plot shows accumulated Poisson counts only inside the selected endpoint fit/display window. The simulator does not currently save a full-spectrum count histogram; the full-spectrum panel is the current model density used to construct the endpoint probabilities.
